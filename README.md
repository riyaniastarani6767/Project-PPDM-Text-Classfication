# 📰 News Headline Text Classification (Detik.com)

This project implements a **text classification system** to categorize news headlines from **Detik.com** using **Multinomial Logistic Regression** and **TF-IDF feature representation**.  
It demonstrates the process of transforming unstructured text into meaningful numerical features for machine learning.

---

## Project Overview
The goal of this project is to automatically classify Indonesian news headlines into specific categories (e.g., *Politics, Sports, Technology, Economy*) using traditional machine learning techniques.  
The project emphasizes **text preprocessing, feature extraction, and model evaluation**.

---

## Features
- **Data Cleaning:** Lowercasing, stopword removal, and punctuation cleaning  
- **Feature Extraction:** TF-IDF vectorization for text representation  
- **Model Training:** Multinomial Logistic Regression  
- **Evaluation:** Accuracy, confusion matrix, and classification report visualization  
- **Result Interpretation:** Keyword analysis and feature importance exploration  

---

## Machine Learning Workflow
1. **Load dataset** containing Detik.com news headlines  
2. **Preprocess text** (tokenization, stopword removal, normalization)  
3. **Transform text** into TF-IDF feature vectors  
4. **Train and evaluate** the Multinomial Logistic Regression model  
5. **Visualize** results with metrics and confusion matrix  

---

## Tech Stack
- **Language:** Python  
- **Libraries:** Pandas, Scikit-learn, Matplotlib, NLTK  

---

## Results
- Achieved reliable performance in multi-class headline classification  
- Model interpretable and easily extendable for real-world applications
